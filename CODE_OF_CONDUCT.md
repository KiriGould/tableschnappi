# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. Please read it there — it is the authoritative text, and linking to it
means this copy can never drift out of date.

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment of any kind is not welcome here.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and
when representing the project in public.

## Reporting

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/KiriGould/tableschnappi/security/advisories/new)
— it is the one reporting channel this project has that is private to you and
the maintainer, and it is not limited to security issues. Reports will be
handled privately and in confidence.

This is a small side project with a single maintainer, so there is no review
committee and no formal SLA. Reports will be read and acted on as promptly as
is reasonable.
